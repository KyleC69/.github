# Support

## Getting help

If you need help using or contributing to a repository that inherits these defaults:
- review the repository documentation first
- search existing issues and discussions
- open a new issue or discussion when a public answer may help others

## Good support requests

Please include:
- what you are trying to do
- what happened instead
- steps already attempted
- relevant versions, logs, screenshots, or examples

## Security concerns

Do not use support channels for security reports. Follow the private reporting process in SECURITY.md.

## Response expectations

Support is provided on a best-effort basis and response times may vary.
