# Contributing

Thanks for your interest in contributing.

## Before you start

- Search existing issues and pull requests before opening a new one.
- Keep changes focused and scoped to the problem being addressed.
- Be respectful in all interactions and follow the Code of Conduct.

## Reporting issues

When reporting a bug, include:
- a clear summary of the problem
- expected behavior and actual behavior
- reproduction steps
- relevant environment details
- logs, screenshots, or examples when helpful

## Suggesting changes

Feature requests should explain the problem being solved, the expected outcome, and any relevant alternatives already considered.

## Pull requests

To help reviews move quickly:
- keep pull requests small and focused
- write clear titles and descriptions
- link related issues when applicable
- update documentation when behavior changes
- ensure any existing checks pass before requesting review

## Review expectations

Maintainers may request updates before merging. Submissions that are incomplete, overly broad, or out of scope may be declined.

## Security issues

Do not open public issues for suspected security vulnerabilities. Use the private reporting instructions in SECURITY.md instead.
